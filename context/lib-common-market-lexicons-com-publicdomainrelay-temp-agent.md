# Context: lib-common-market-lexicons-com-publicdomainrelay-temp-agent

Repository: `atproto-market`

This context exists so callers can read and write the agent-class and agent-skill records of the publicdomainrelay.temp namespace through a typed, validated interface rather than hand-rolled JSON. The class record is a template that names a skill bundle and an optional parent class so an agent can be instantiated from it seeded with those skills, and the skill record carries the capability text plus example records and path-annotated property references that resolve values out of those examples. Both files are machine-generated by "@atproto/lex" and are not meant to be edited by hand; the thin class.ts and skill.ts barrels give importers a stable module path whose default export is the record validator.
